HOW IT WORKS

One schema. Three ways of reading.

Generic pipelines flatten everything to text and lose the relationships. nexDoc keeps each artifact's native structure, then maps it all onto the same node/edge shape.

Native extraction

A formula stays a formula. A flowchart arrow stays an edge with a direction. Each adapter reads its file in its own terms — no flatten-to-text first step.

One common schema

Spreadsheets, documents and diagrams all converge on the same regions + relationships + checks. A downstream system integrates once, not once per file type.

Validated, not just confident

Every region carries a confidence from a real signal, and artifact-level checks — does the total match its line items? does every edge hit a real node? — can fail independently.

A pipeline you can watch

Regions stream out of the adapters as they're found — diagram shapes first, labels as OCR reads them — instead of after a spinner. The engine warms its OCR model in the background and caches results by content hash.
